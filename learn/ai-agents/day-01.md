# Day 1 — AI Agents giris

## ELI5
Q: AI agent nedir, normal programdan farki ne?
A: AI agent, ortama bakip, ogretilen veya sabit kurallar dogrultusunda, degisen kosullara gore karar verebilen bir programdir. Normal program ise durum degisse de ayni listeyi korur; agent karar verir.


## Senaryo
Q: Tercihlerini ogrenip evi ısıtan akilli termostat hangi agent turu, neden?
A: Learning agent — cunku tercihleri ogreniyor; sadece anlik kurala tepki vermiyor.


## Deep Dive
Q: Goal-based ile utility-based agent farki nedir?
A: Goal-based hedefe ulasti mi diye evet/hayir ile ilerler. Utility-based ise olabilecek senaryolar icinden en uygun olani (skora gore) secer.


## Kisisel baglanti
Q: Bugun kullandigin bir agent (Cursor, ChatGPT...). Perception / decision / action / goal diye ayir.
A: Cursor kullaniyorum.
- Perception: benim yazdiklarim, acik dosyalar, terminal ciktisi
- Decision: ogretilmis bilgiler + guvenilir kaynaklarla ne yapacagina karar vermesi
- Action: kod yazmak, dosya duzenlemek, komut calistirmak
- Goal: ogrenmeyi / isi kolaylastirmak (otomasyon, gorevi bitirmek)
