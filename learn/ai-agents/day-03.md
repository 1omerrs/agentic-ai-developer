# Day 3 — Agent framework'leri

## Comparison
Q: LangChain ile LlamaIndex tasarim felsefesi farki nedir?
A: LangChain genel agent ve tool yonetimi icin. LlamaIndex veri / PDF / dokuman icin (okuyup sormak).



## Use Case
Q: PDF'lerimle sohbet eden agent istiyorum. Hangisi daha uygun, neden?
A: LlamaIndex — asil amaci bu; kutuphaneci gibi dokumanlari okuyup soruya cevap verir.



## Second Use Case
Q: GitHub API + terminal ile CI hatalarini duzelten agent. Hangisi / ne uygun, neden?
A: LangChain — tool'lu genel agent isi (API + terminal). Cursor da benzer coding agent ornegi.
