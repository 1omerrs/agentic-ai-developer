# Day 5 — Agent mimarisi (ReAct, MRKL, Self-correction)

## ReAct (kendi cumlem)
Q: ReAct ne demek? Kendi cumlenle anlat.
A: Agent gelen sorguyu gorur, gider bakar (tool/arama); sonuc net ise cevabi gosterir, degilse tekrar bakar. Yani: dusun → yap → gor → gerekirse tekrar.



## ReAct — Day 4 baglantisi
Q: Day 4 research assistant'inde ReAct'i nerede gordun? (dusun / yap / gor)
A:
- Dusun: arama yapmam lazim
- Yap: webte arama yap
- Gor: cevabi / sonucu getirir (sonra kullaniciya yazar)



## MRKL
Q: MRKL'nin fikri ne? (isleri bolmek) Bir ornekle anlat.
A: Amaci isleri bolerek is yukunu azaltmak ve daha iyi sonuc almak.
Ornek: beyin dusunur, "yap" karar verir / tool calisir, sonuc cevabi getirir (roller ayrilir).



## Self-correction
Q: Self-correction ne demek? ReAct'ten farki / iliskisi ne?
A: ReAct arama/dongu yapar. Self-correction ise aramada dogru veya tam sonuc alamadiysa tekrar aramasini / duzeltmesini saglayan kisimdir. Yani ReAct'in "yanlissa tekrar dene" hali.



## Karsilastirma
Q: Basit chatbot ile ReAct agent arasindaki en buyuk fark nedir?
A: Chatbot senin yazdiklarina cevap verir. ReAct agent dusunur, arka planda sorgu/tool ile kontrol eder, surecler tamamlaninca cevap verir.
